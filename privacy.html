CutEasy Privacy Policy

Last updated September 2, 2026

概述

CutEasy 的设计原则是将用户内容保留在用户自己的 Mac 上。使用本应用无需注册账号或登录。

本地存储

剪贴板历史、导入图片、截图、图片批注、OCR 识别结果和应用偏好设置均保存在用户 Mac 上的 CutEasy 沙盒容器中。

开发者不收集数据

CutEasy 不会将剪贴板内容、保存的图片、批注、OCR 结果或翻译内容发送给开发者、广告网络或分析服务。CutEasy 不包含广告或第三方分析 SDK。

剪贴板访问

只有用户主动启用剪贴板历史后，CutEasy 才会开始监控剪贴板。用户可以随时暂停监控，并可在设置中清除全部历史记录。

截图文件夹访问

截图监控为可选功能。CutEasy 只访问用户通过 macOS 文件选择器主动选择的文件夹，并使用应用范围的 security-scoped bookmark 在重启后恢复访问。用户可以随时在设置中停止监控并撤销访问。

辅助功能权限

辅助功能权限为可选权限，仅在用户主动使用“一键粘贴”时用于发送 Command-V。若未授权，CutEasy 只会把所选内容复制到系统剪贴板，用户仍可手动粘贴。

保留与删除

内容会保留在用户的 Mac 上，直到用户删除单条记录、清除 CutEasy 历史或移除应用的本地数据。

联系我们

隐私相关问题请发送邮件至 moonintahiti@163.com。产品使用帮助请访问 CutEasy 技术支持。

Overview

CutEasy is designed to keep user content on the user's Mac. No account or login is required.

Local storage

Clipboard history, imported images, screenshots, image annotations, OCR results, and saved application preferences are stored in CutEasy's sandbox container on the user's Mac.

No developer collection

CutEasy does not send clipboard content, saved images, annotations, OCR results, or translations to the developer, advertising networks, or analytics providers. CutEasy does not use advertising or third-party analytics SDKs.

Clipboard access

Clipboard monitoring is disabled until the user chooses to enable clipboard history. It can be paused at any time, and saved history can be deleted from Settings.

Screenshot folder

Screenshot monitoring is optional. CutEasy accesses only a folder selected through the macOS file picker and stores an app-scoped security-scoped bookmark so that access can continue after relaunch. Folder access can be revoked in Settings.

Accessibility

Accessibility permission is optional and is used only to send Command-V after the user invokes a one-click paste action. Without permission, CutEasy copies the selected item to the system clipboard and the user can paste manually.

Retention and deletion

Content remains on the user's Mac until the user deletes individual items, clears CutEasy history, or removes the app's local data.
